## Task: Redesign the homepage with a dark theatrical style

Read `AGENTS.md` first and inspect the current homepage implementation before making changes.

I want to redesign the homepage so it feels more distinctive, artistic, and memorable while still remaining clean and professional for Ph.D. applications in computational media / HCI / creative technology.

### Overall visual direction

Please redesign the homepage using a **dark theme** with a strong **editorial / theatrical** feel.

The homepage should center around:
- **text on the left**
- **a large portrait image on the right**
- a minimalist layout with strong typography
- no obvious card borders around the portrait
- the overall effect should feel like **a researcher-artist portfolio**, not a corporate website

The mood should be:
- dark
- elegant
- minimal
- creative
- slightly theatrical
- visually distinctive, but still professional

### Main composition

Use a two-column hero section on desktop:

**Left column**
- My name as the main headline
- Degree/program information
- A short tagline
- A concise personal/research introduction
- A row of icon-based links (email, LinkedIn, CV)

**Right column**
- Replace the current personal photo with the new theatrical portrait image
- The photo should be prominent and visually integrated into the page
- Do **not** place the image inside a visible card or strong bordered box
- Let the image feel like part of the composition, with soft edges or a clean rectangular crop
- The image should remain clearly visible and large enough to create impact

The main impression should be: **words + person**

### Color palette

Use a dark background, such as:
- near-black
- deep charcoal
- or a very dark brown-black with warmth

Text should be high-contrast but not pure white:
- use off-white / warm light gray for body text
- use a slightly brighter white or ivory for headings
- use a muted accent color inspired by the portrait, such as:
  - dusty blue
  - muted teal
  - or a restrained warm cream

Avoid oversaturated neon colors.

### Typography

Typography should be the main design feature.

Please create a clear hierarchy:
- Name: large and bold
- Tagline: prominent but secondary
- Supporting info: smaller and lighter
- Body text: readable, elegant, not too dense

Preserve a calm reading experience. Avoid making the text block too wide.

If the current font works well, keep it. Otherwise, use a clean serif/sans-serif pairing only if it can be done simply and consistently.

### Portrait image treatment

Use the uploaded theatrical portrait as the homepage hero image.

Design requirements:
- no obvious border box
- no harsh drop shadow
- allow the image to stand out through scale and composition instead
- optionally use a subtle fade, soft edge, or shadow blending into the dark background
- crop carefully so the face and flowers remain the focal point
- preserve the expressive theatrical quality of the image

Do not add decorative frames or scrapbook effects.

### Content structure

The homepage should still communicate that I am:
- a computer science student
- a theater artist
- a researcher interested in storytelling, participation, and computational media

Preserve the core content, but feel free to tighten the layout and reduce visual clutter.

Do not invent any new achievements or research claims.

### Links row

Keep the icon row for:
- Email
- LinkedIn
- CV

Make it elegant and subtle on the dark background.
Use hover effects that are minimal and refined.

### Navigation

Keep the top navigation simple and clean.
It should visually recede compared to the hero content.

### Responsive behavior

On desktop:
- strong two-column layout

On tablet/mobile:
- stack vertically
- text first, image after (or image first only if it looks clearly better)
- preserve strong typography and spacing
- avoid awkward cropping

### What to avoid

Do not:
- add busy gradients
- add glassmorphism
- add large UI cards
- make it look like a startup landing page
- make it feel too playful or messy
- over-design the page

### Goal

The final result should feel like a distinctive homepage for someone working between:
- computing
- creativity
- storytelling
- performance

It should feel more visually unique than the current version, while still being appropriate to send to professors.

After making changes:
- summarize the visual changes
- list files modified
- confirm the page works on desktop and mobile
